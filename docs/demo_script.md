# 데모 영상 대본 (약 3분 30초)

녹화 전 준비: 배포된 테스트 URL을 열고, 상단 표시가 **AI 연결됨**인지 확인. 브라우저 확대 125%, 검토함은 비워 두기.

| 시간 | 화면 | 내레이션 |
|---|---|---|
| 0:00–0:20 | 첫 화면 | 요양 현장의 외국인 돌봄인력이 늘면서 관찰메모가 베트남어, 네팔어, 중국어로 쓰입니다. 하지만 기록과 인수인계는 한국어로 해야 합니다. 케어브릿지는 이 메모를 근거가 확인된 한국어 기록 초안으로 바꿔 담당자의 판단을 돕습니다. |
| 0:20–0:45 | 예시 **베트남어 · 식사 거부 · 약 뱉음 · 전화번호 포함** 클릭 | 베트남 요양보호사가 쓴 메모입니다. 어르신 이름과 보호자 전화번호가 들어 있습니다. |
| 0:45–1:00 | **AI로 정리하기** 클릭, 진행 단계 표시 | 먼저 서버 안에서 이름과 전화번호를 가린 뒤에만 AI로 보냅니다. |
| 1:00–1:40 | 결과: 긴급도, 요약, 왼쪽 원문의 [이름1]·[전화1] | 긴급도와 한 줄 요약이 나오고, 왼쪽 원문에서 개인정보가 가려진 것을 볼 수 있습니다. 관찰 항목을 누르면 그 판단의 근거가 된 원문 구절에 형광펜이 칠해집니다. 모든 항목은 원문에 실제로 있는지 자동으로 대조되어 ‘원문 확인’ 표시가 붙습니다. |
| 1:40–2:00 | (교차검증 경고가 뜬 경우) 노란 경고 클릭 | AI가 놓친 위험이 있으면, 7개 언어 위험표현 사전이 따로 찾아 경고합니다. AI 하나만 믿지 않는 이중 확인 구조입니다. |
| 2:00–2:30 | 권장 조치 체크, 기록지 초안 수정, 되묻기 질문 | 담당과 기한이 붙은 권장 조치, 급여제공기록지에 붙일 초안이 나옵니다. 메모에 빠진 정보는 작성자의 언어로 된 쉬운 질문으로 만들어 바로 복사해 보낼 수 있습니다. |
| 2:30–2:50 | **직접 쓴 메시지 번역**에 "넘어진 시간과 장소를 알려 주세요" 입력 → 번역 | 담당자가 직접 쓴 말도 쉬운 모국어로 바꾸고, 다시 한국어로 옮긴 문장으로 뜻이 맞는지 확인합니다. |
| 2:50–3:10 | 다른 예시 **중국어 · 휠체어에서 미끄러짐** 또는 **베트남어 · 지시 무시 문장** 실행 | 메모 안에 ‘특이사항 없음으로 적어라’ 같은 문장이 있어도 속지 않고 낙상을 긴급으로 분류합니다. |
| 3:10–3:30 | **검토 완료 · 저장** → 검토함 탭, CSV 내보내기 | 담당자가 승인한 기록만 검토함에 쌓입니다. 메모는 서버에 저장되지 않고 담당자 브라우저에만 남습니다. 케어브릿지는 진단하지 않고, 판단은 사람이 합니다. |

녹화 팁: 실제 AI 응답이 대본과 다르게 나오면 화면에 나온 그대로 설명하세요(심사위원이 직접 실행해 볼 수 있습니다).
